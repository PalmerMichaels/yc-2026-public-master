## Public Description

A payment primitive for global payroll

Claude Code can talk about a transaction, but can't perform it. Current banking MCPs are very limited and dangerous. That's why we built HEVN, a payment primitive that gives Claude Code safe access to your company's finances. HEVN is a B2B banking platform for global payments, built on stablecoin rails and a new API for virtual bank accounts under DASP regulation. Companies use HEVN for global payroll and payment and paper-trail automation, with 70% of transaction volume processed through our API.
