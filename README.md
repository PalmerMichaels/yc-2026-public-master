# YC 2026 Public Software Reimplementations

Public master tracker for the YC 2026 public software reimplementation initiative.

Scope:
- Discover every YC 2026 company from Y Combinator/public sources.
- Track each company as a task with source links and a copyability classification.
- For copyable pure-software companies, create a public `<company-slug>-public` repository and build an original clean-room implementation of the public product functionality.
- Mark companies not copyable when they require hardware, regulated approvals/data/processes, non-public integrations, proprietary datasets, or other dependencies that cannot be recreated safely.

Clean-room constraints:
- Do not copy proprietary source, private data, trademarks, logos, branding, copy, or assets.
- Do not bypass access controls or use non-public integrations.
- Implement original public software based on public descriptions and observable behavior only.
